# জন্মদিন স্টুডিও — ব্যক্তিগত জন্মদিন উদযাপন প্ল্যাটফর্ম

## যা যা আছে
- যেকোনো Google/Gmail অ্যাকাউন্ট দিয়ে নিরাপদ লগইন।
- প্রথম লগইনে স্বয়ংক্রিয় ব্যক্তিগত প্রোফাইল তৈরি।
- প্রত্যেক ব্যবহারকারী শুধু নিজের জন্মদিনের আয়োজন দেখতে, তৈরি, সম্পাদনা ও মুছতে পারবেন।
- প্রতিটি আয়োজনের আলাদা শেয়ার লিংক, QR কোড, প্রিভিউ।
- বাংলা নাম ও বাংলা শুভেচ্ছাবার্তা।
- জন্মদিনের পাতায় কেক, মোমবাতি, আতশবাজি এবং গান।
- ঐচ্ছিক অডিও ও অতিরিক্ত ফাইলের লিংক।
- শুধু ছবি ImgBB API-তে আপলোড হবে; ছবি নির্বাচন, প্রিভিউ, আপলোড অগ্রগতি এবং ImgBB ডিলেট পেজ খোলার ব্যবস্থা আছে।

## Firebase সেটআপ
Firebase প্রজেক্ট: `birthday-wish-15e13`

1. Firebase Console → Authentication → Sign-in method থেকে Google চালু করুন।
2. Authentication → Settings → Authorized domains-এ `hkshahadot24-netizen.github.io` যোগ করুন।
3. Firestore Database → Rules-এ এই ZIP-এর `firestore.rules` ফাইলের সম্পূর্ণ কোড Publish করুন।
4. Realtime Database এই অ্যাপ ব্যবহার করে না; `database.rules.json` শুধু অপ্রয়োজনীয় RTDB অ্যাক্সেস বন্ধ রাখে।

## ImgBB ছবি আপলোড
- API endpoint: `https://api.imgbb.com/1/upload`
- API key `imgbb-config.js`-এ রাখা আছে।
- সমর্থিত ছবি: JPG, PNG, GIF, WEBP, AVIF; সর্বোচ্চ ৩২ MB।
- ছবি নির্বাচন করলে লোকাল প্রিভিউ দেখা যায়; আপলোডে অগ্রগতি দেখায়।
- সফল আপলোডের URL জন্মদিনের পাতার ছবিতে যুক্ত হয়; এরপর Firebase-এ পাতাটি Save করতে হবে।
- ImgBB-এর `delete_url`-এর মাধ্যমে নতুন ট্যাবে ডিলেট পেজ খোলা হয়। ImgBB-তে ডিলেট চূড়ান্ত করতে ওই পেজে নিশ্চিত করতে হবে। এরপর ফর্মে “ছবি সরান” চাপ দিয়ে পাতাটি Save করলে শেয়ার করা পাতাতেও ছবিটি আর দেখাবে না।
- ImgBB-এর প্রকাশ্য API-তে সরাসরি নির্ভরযোগ্য DELETE endpoint নেই; তাই ডিলেট URL-এ ব্যবহারকারীর নিশ্চিতকরণ প্রয়োজন।

**নিরাপত্তা:** ব্রাউজার-সাইডে থাকা API key ওয়েবসাইটের সোর্স থেকে দেখা সম্ভব। এই কী শুধু ImgBB আপলোডের জন্য; প্রয়োজনে ImgBB অ্যাকাউন্ট থেকে কী পরিবর্তন/রোটেট করুন। API key-কে গোপন সার্ভার-সাইড সিক্রেট হিসেবে গণ্য করা যাবে না।

## অন্যান্য আপলোড ব্যবস্থা
Cloudflare Worker, GitHub Assets uploader এবং সব ধরনের সাধারণ ফাইল আপলোড কোড বাদ দেওয়া হয়েছে। গান ও অতিরিক্ত ফাইলের বিদ্যমান URL ইনপুট আগের মতোই রাখা হয়েছে; সেগুলোর জন্য কোনো ফাইল আপলোড চালু নেই।

## পাবলিক জন্মদিনের পাতার নতুন উৎসব ডিজাইন
- ImgBB-তে আপলোড করা পাবলিক ছবির URL `photoUrl` হিসেবে Firestore-এ সংরক্ষিত হয় এবং শেয়ার লিংকে ছবিটি দেখা যায়।
- ছবির চারপাশে ঘূর্ণায়মান উৎসবের রঙ, ঝিলিক ও আলোর অ্যানিমেশন থাকে।
- ব্যক্তিগত শুভেচ্ছাবার্তা শুরুতে গিফট বক্সের ভেতরে লুকানো থাকে; বক্সে চাপ দিলে চিঠিটি খুলে যায়।
- চিঠির সঙ্গে গুপ্তধনের বাক্স, রত্ন ও সোনার কয়েনের অ্যানিমেশন দেখানো হয়।
